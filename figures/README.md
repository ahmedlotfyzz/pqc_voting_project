# Figures

These PNG files are the dashboard-style summary visualisations produced by
`src/11_dashboard.py` during the evaluation pipeline. They summarise each phase of
the project (architecture, PQC primitives, blockchain, consensus, scale test,
storage, adversarial suite, and the overall evaluation).

Note: the publication-quality academic figures (Fig. 1-Fig. 6) that appear in the
manuscript are regenerated from the raw logs in `../results/` by the analysis
scripts; these dashboard images are the human-readable per-phase summaries.
